# Simple Portfolio

A small, responsive portfolio made with Next.js.

## Run it locally

1. Install Node.js (version 20 or newer).
2. Open this folder in VS Code.
3. In the VS Code terminal, run `npm install` and then `npm run dev`.
4. Open the local address printed in the terminal (usually http://localhost:3000).

## Personalize it

Edit `app/page.tsx` to update your name, introduction, skills, projects, email, and social links. Edit `app/globals.css` to change the colors and layout.

## Push it to GitHub

Create an empty repository on GitHub, then in this folder run:

```sh
git init
git add .
git commit -m "Create simple portfolio"
git branch -M main
git remote add origin YOUR_GITHUB_REPOSITORY_URL
git push -u origin main
```
